Documentation

From first install to everyday calls.

Beginner-friendly walkthrough: install on your computer, finish first-time setup, then use Kalfi in real meetings. On Mac, Apple may show a “damaged” warning — that is normal for our unsigned build; the fix is in the install steps.

01

Install

Download the build for your OS, then follow the matching steps below.

Prefer the file named like kalfi-…-mac.dmg (not older names without -mac).

1. Download & open the installer

  1. Click Download on the homepage (it detects macOS automatically).
  2. Wait until the download finishes. Check your browser’s downloads bar or the Downloads folder.
  3. Double-click the .dmg file. A small window opens with the Kalfi icon.
  4. Drag Kalfi onto the Applications folder icon.
  5. Open Finder → Applications and launch Kalfi.

2. If Mac says “Kalfi is damaged and can’t be opened”

This does not mean the file is broken. macOS is blocking apps that are not Apple-notarized yet. Try Method A first (no Terminal).

Method A — Privacy & Security (easiest)

  1. Open System Settings (Apple menu  → System Settings).
  2. Click Privacy & Security in the left sidebar.
  3. Scroll to the Security section.
  4. If Kalfi is listed as blocked, click Open Anyway.
  5. Confirm, enter your password if asked, then open Kalfi again from Applications.

Tip: “Open Anyway” often appears only after you tried to open Kalfi once.

Method B — Control-click → Open

  1. Open Finder → Applications and find Kalfi.
  2. Hold Control and click Kalfi (or right-click / two-finger click).
  3. Choose Open, then confirm Open again.

Method C — only if A and B still fail

  1. Open Terminal (⌘ + Space, type Terminal, Enter).
  2. Paste this line and press Enter:
                    xattr -cr /Applications/Kalfi.app
  1. No output is normal. Open Kalfi again from Applications.
  1. Download the Windows installer from the homepage (.exe, name like kalfi-…-win-setup.exe).
  2. Double-click the file in your Downloads folder.
  3. If Windows shows Windows protected your PC (SmartScreen): click More info, then Run anyway.
  4. Follow the installer (Next → Install).
  5. Open Kalfi from the Start menu or desktop shortcut.
  1. Download the .AppImage from the homepage download button (Linux is auto-detected).
  2. Make it executable: right-click → Properties → allow “executable” / run as program (wording varies by desktop).
  3. Or from a terminal:
    chmod +x kalfi-*.AppImage && ./kalfi-*.AppImage
  4. Launch the app, then continue with first-time setup below.
02

First-time setup

Do this once after install so the overlay can hear the call and answer.

  1. Allow permissions. When macOS (or your OS) asks for microphone / system audio access, allow it — Kalfi needs that to hear the meeting.
  2. Add your AI key (BYOK). Open Settings in the app and paste an OpenAI or OpenRouter API key (or a compatible base URL). The key stays on your device for BYOK.
  3. Pick models. Choose chat + transcription models you already use. You can change them later per install.
  4. Optional stealth. Set a custom display name and logo, and hide from Dock if you want the process list to look like a boring utility — not an AI brand.
  5. Create your first session. Open Sessions, create one, pick mode (Interview / Client / Chat), answer length, tone, and meeting language, then save.
03

Daily use

The loop you run before and during every call.

Before the call

  1. Open Kalfi and select (or create) the right session for this meeting.
  2. Confirm mode, length, tone, and language match the room.
  3. Join Google Meet / Zoom / your conferencing app as usual.
  4. Start listening in Kalfi so the overlay floats above the call.

During the call

  1. Watch the live transcript for the question that matters.
  2. Read the suggested reply — say it out loud in your own voice.
  3. Adjust length/tone if answers feel too long or too stiff.
  4. Use Mic Ask when you want to ask Kalfi something without typing.

After the call

  1. Stop listening / end the session when you leave the meeting.
  2. Skim session history if you need notes from what was said.
  3. Reuse the same session next time, or clone one for a different client.

Good habits

  • Test screen-share protection on your exact OS + Meet/Zoom combo before a high-stakes call.
  • Keep answers short enough to say naturally — balanced + neutral is a strong default.
  • If the room forbids assistance, turn Kalfi off. Respect the rules of the meeting.
