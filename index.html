Questions

The things people ask before downloading.

Mac says “Kalfi is damaged and can’t be opened” — is my download broken?

No. That message is Apple’s Gatekeeper blocking an app that is not Apple-notarized yet. The file is fine. Follow Docs → Install → macOS: try System Settings → Privacy & Security → Open Anyway, or Control-click → Open. Only if those fail, use the one-line Terminal fix (xattr -cr /Applications/Kalfi.app).

How do I install and use Kalfi for the first time?

See the full guide in Documentation — install, first-time setup, and daily use. On Mac prefer kalfi-…-mac.dmg.

Does my API key ever touch your server?

No. On BYOK the key lives in encrypted storage on your machine and talks straight to OpenAI or OpenRouter. Our API only appears when you choose Hosted / Pro, and then the provider key is ours, not yours.

What actually runs where?

The app runs on your computer — audio capture, transcript, session history, all local. This page is static hosting. The Pro backend runs on a small VPS and only handles login, subscription state and the model proxy.

Is this allowed in my interview or meeting?

That depends on the room. Kalfi is built for calls where assistance is permitted — client work, internal meetings, sales, practice, language support. If an employer, school or client says no, respect it.

Which providers and models work?

Anything OpenAI-compatible: OpenAI directly, OpenRouter for model choice, or a custom base URL for your own gateway. Chat and transcription models are configurable per install.

Windows and Linux builds?

Yes. macOS, Windows, and Linux installers ship from the latest GitHub Release. The homepage download button detects your OS and downloads the matching file directly. See Docs → Install for SmartScreen and AppImage notes.
